# Verification — finplan-content
# Run this checklist before reporting any content/education change done.

1. **Memory loaded.** Did I read all four `.learn` files (canonical, errors, glossary, lessons)?
2. **The "why" lands.** Does every input/control in scope answer "what is this and why does it matter to my plan?" in plain language — no unglossed jargon, no bare field?
3. **Attribution present.** Is every methodology the screen invokes named to its source in the user's words (Trinity/Bengen, Sethi, Collins, Housel)?
4. **Glossary-locked.** Does every load-bearing phrase match `glossary.md` exactly, with no banned synonym ("the target," "interest rate," "wants/needs," "you failed")? Is glossary.md updated if a phrase changed?
5. **Honest framing, CFP-validated.** Does every projection read as an estimate (never "guarantee"/"will have")? Is every engine simplification (income inflation, pre-tax, constant/sampled returns) caveated in plain language *where the number appears* — and confirmed correct by CFP/canonical?
6. **Non-judgmental.** Is no spending category labeled bad/too much/wasteful? Does Sethi framing hold?
7. **Voice.** Did I apply preston-writing — zero banned constructions, no "genuinely/honestly/straightforward," no "the research shows" without a citation, no em-dash overuse, no tricolons? Does it read human?
8. **Sourced.** Does every factual/methodology claim trace to a primary source (researching-with-confidence)? Nothing invented?
9. **Read in place.** Did I read the copy in Claude_Preview, in context — it clarifies, fits the layout without overflow, reads at a first-timer's level, and no scary number dead-ends?

If any check fails, fix the copy before reporting done. Copy that is clear but unsourced fails. Copy that is correct but reads as AI fails.
