### Critical

Canonical §1 itself flags this cliff as confidence-medium / CFP-to-refine. A tooltip would set honest expectations.
- **Required-portfolio card correctly explains the driver and the fully-covered $0 case (`:285-288`)** — this is exactly the CFP-grade transparency the project asks for. Good.
